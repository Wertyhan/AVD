## Тема

«Розподілена обробка великих даних за допомогою Apache Spark»

## Мета роботи

ознайомитися з архітектурою та принципами роботи Apache Spark як платформи розподіленої обробки великих даних. Отримати практичні навички завантаження, очищення, трансформації та агрегації великих наборів даних за допомогою Spark DataFrame та PySpark. Навчитися виконувати аналітичні операції над великими даними та використовувати Spark SQL для формування аналітичних запитів.

## Програмне забезпечення

Для виконання практичного заняття використовується безкоштовне програмне забезпечення з відкритим кодом:

- Apache Spark — платформа розподіленої обробки великих даних;
- PySpark — Python API для Apache Spark;
- Python 3 — мова програмування;
- OpenJDK — середовище виконання Java, необхідне для роботи Apache Spark;
- Jupyter Notebook або Visual Studio Code — середовище розробки;
- Apache Hadoop — може використовуватися для локальної роботи Spark з HDFS;
- Git — за необхідності для керування програмним кодом.

Для виконання роботи на одному персональному комп'ютері Apache Spark може бути запущений у локальному режимі, що дозволяє використовувати всі доступні обчислювальні ядра комп'ютера.

## Теоретичні відомості (розділи з методички)

1. Apache Spark — основні компоненти: Spark Core, Spark SQL, Structured Streaming, MLlib, GraphX. У межах роботи основна увага приділяється Spark Core та Spark SQL.
2. PySpark — Python API для Apache Spark; створення Spark-сесії.
3. DataFrame — розподілена структура даних у вигляді рядків і стовпців; приклад завантаження CSV-файлу; основні операції.
4. Трансформації та дії; lazy evaluation (трансформації виконуються лише після виклику дії).
5. Spark SQL — SQL-запити над DataFrame.

Встановити та перевірити працездатність Python, Apache Spark, PySpark та Jupyter Notebook або Visual Studio Code.

### Завдання 2. Завантаження даних

Завантажити обраний датасет у Spark DataFrame.

Визначити:

- кількість записів;
- кількість атрибутів;
- назви полів;
- типи даних;
- кількість пропущених значень.

### Завдання 3. Попередня обробка

Виконати:

- обробку пропущених значень;
- приведення типів;
- видалення дублікатів;
- формування необхідних похідних атрибутів.

### Завдання 4. Розподілена аналітика

Реалізувати не менше трьох операцій:

- фільтрацію;
- групування;
- сортування;
- агрегацію;
- обчислення статистичних характеристик.

### Завдання 5. Spark SQL

Створити тимчасове представлення DataFrame та виконати не менше трьох SQL-запитів.

### Завдання 6. Порівняння Hadoop MapReduce та Spark

Порівняти MapReduce і Spark за:

- моделлю обчислень;
- використанням оперативної пам'яті;
- продуктивністю;
- зручністю програмування;
- можливостями повторного використання даних.

### Завдання 7. Візуалізація

Побудувати не менше двох графіків за результатами обробки.
