## Тема

Інтелектуальний аналіз великих даних засобами Apache Spark MLlib

## Мета

Мета роботи: ознайомитися з можливостями Apache Spark MLlib для інтелектуального аналізу великих даних. Отримати практичні навички підготовки даних до машинного навчання, формування ознак, побудови та оцінювання моделей класифікації, кластеризації або регресії засобами PySpark.

## Програмне забезпечення

Для виконання практичного заняття використовується безкоштовне програмне забезпечення:

- Apache Spark — платформа розподіленої обробки
- Spark MLlib — бібліотека машинного навчання Apache Spark
- PySpark — Python API для Apache Spark
- Python 3
- OpenJDK
- Jupyter Notebook або Visual Studio Code
- NumPy — числові обчислення
- Pandas — допоміжна обробка даних
- Matplotlib — візуалізація результатів

Усі перелічені засоби можуть використовуватися без придбання комерційних ліцензій.

## Теоретичні відомості (ключові пункти методички)

1. **Apache Spark MLlib** — бібліотека машинного навчання Apache Spark для масштабованого інтелектуального аналізу даних. Підтримуються: класифікація, регресія, кластеризація, рекомендаційні системи, зниження розмірності, ML Pipeline, оцінювання моделей.
2. **Підготовка даних** — перед побудовою моделі необхідно: (1) визначити цільову змінну; (2) вибрати ознаки; (3) обробити пропущені значення; (4) перетворити категоріальні ознаки; (5) сформувати вектор ознак.
3. **VectorAssembler** — трансформатор MLlib, що об'єднує кілька числових або векторних колонок в один векторний стовпець.
4. **ML Pipeline** — структура машинного навчання (схема на рисунку 1 у методичці).
5. **Методи машинного навчання:**
   - класифікація: Logistic Regression, Decision Tree, Random Forest;
   - регресія: Linear Regression, Decision Tree Regression, Random Forest Regression;
   - кластеризація: K-Means.

## Завдання

**Завдання 1. Визначення задачі**
Для обраного датасету визначити одну із задач:
- класифікація;
- регресія;
- кластеризація;
- виявлення аномалій.

Обґрунтувати вибір.

**Завдання 2. Підготовка даних**
Виконати:
- відбір ознак;
- обробку пропущених значень;
- кодування категоріальних ознак;
- формування цільової змінної;
- формування вектора ознак.

**Завдання 3. Формування вибірок**
Розділити дані на: 80 % — навчальна вибірка; 20 % — тестова вибірка.

**Завдання 4. Побудова моделей**
Побудувати дві моделі для обраної задачі.

**Завдання 5. ML Pipeline**
Реалізувати повний конвеєр машинного навчання: Data → Preprocessing → Feature Engineering → Model → Prediction → Evaluation

**Завдання 6. Оцінювання**
Визначити відповідні метрики якості моделі.

**Завдання 7. Порівняння моделей**
Порівняти щонайменше дві моделі за відповідними метриками. Результати подати у вигляді таблиці.

**Завдання 8. Аналіз результатів**
Проаналізувати:
- які ознаки є найбільш інформативними;
- які помилки допускають моделі;
- яка модель забезпечує кращі значення обраних метрик;
- можливі шляхи вдосконалення моделі.
