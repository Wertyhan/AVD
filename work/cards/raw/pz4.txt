з дисципліни «Аналітика великих даних»

на тему: «Зберігання та аналіз великих даних у NoSQL-сховищі MongoDB»

Мета роботи: ознайомитися з принципами організації NoSQL-сховищ та документною моделлю MongoDB. Отримати практичні навички створення бази даних, колекцій, імпорту великих наборів даних, виконання запитів, індексації та агрегування даних. Навчитися використовувати MongoDB як сховище результатів обробки великих даних.

Програмне забезпечення

Для виконання роботи використовується безкоштовне програмне забезпечення:

\- MongoDB Community Edition — документно-орієнтована NoSQL

СКБД;

\- MongoDB Compass — графічний інтерфейс MongoDB;

\- MongoDB Shell (mongosh) — командний інтерфейс;

\- PyMongo — Python-драйвер MongoDB;

\- Python 3;

\- Jupyter Notebook або Visual Studio Code.

Для виконання роботи MongoDB може бути встановлена локально на персональному комп'ютері.

Завдання 3. Імпорт даних

Завантажити оброблений набір даних до MongoDB.

Визначити:

\- кількість документів;

\- структуру документів;

Завдання 4. Виконання запитів

Реалізувати не менше п'яти запитів:

\- пошук;

\- фільтрація;

\- сортування;

\- обмеження результатів;

\- вибір необхідних полів.

Створити не менше трьох конвеєрів агрегації (або пайплайни агрегації) - це механізм у MongoDB для послідовної обробки, фільтрації, трансформації та аналізу даних.
