Теоретичні відомості

1. Apache Spark

Apache Spark — розподілена обчислювальна платформа з відкритим програмним кодом, призначена для обробки великих обсягів даних.

Основними компонентами Spark є:

• Spark Core;

• Spark SQL;

• Structured Streaming;

• MLlib;

• GraphX.

У межах цієї роботи основна увага приділяється Spark Core та Spark SQL.

2. PySpark

PySpark — Python API для Apache Spark, що дозволяє виконувати розподілену обробку даних мовою Python.

Завдання на практичне заняття

Для виконання роботи використовуйте той самий датасет Kaggle, який був обраний для практичного заняття № 1.

Завдання 1. Підготовка середовища

Встановити та перевірити працездатність Python, Apache Spark, PySpark та Jupyter Notebook або Visual Studio Code.

Завдання 2. Завантаження даних

Завантажити обраний датасет у Spark DataFrame.

Визначити:

- кількість записів;

- кількість атрибутів;

- назви полів;

- типи даних;

- кількість пропущених значень.

Завдання 3. Попередня обробка

Виконати:

- обробку пропущених значень; - приведення типів; - видалення дублікатів; - формування необхідних похідних атрибутів.

Завдання 4. Розподілена аналітика

Реалізувати не менше трьох операцій:

- фільтрацію;

- групування;

- сортування;

- агрегацію;

- обчислення статистичних характеристик.

Завдання 5. Spark SQL

Створити тимчасове представлення DataFrame та виконати не менше трьох SQL-запитів.

Завдання 6. Порівняння Hadoop MapReduce та Spark

Порівняти MapReduce і Spark за:

- моделлю обчислень;

- використанням оперативної пам'яті;

- продуктивністю;

- зручністю програмування;

- можливостями повторного використання даних.

Завдання 7. Візуалізація

Побудувати не менше двох графіків за результатами обробки.
