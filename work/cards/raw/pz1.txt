з дисципліни «Аналітика великих даних»

на тему: Обробка великих даних у середовищі Hadoop (HDFS, MapReduce, Hive).

Мета роботи:

- ознайомитися з архітектурою та принципами роботи платформи Apache
Hadoop;

- навчитися працювати з HDFS (Hadoop Distributed File System);

- засвоїти базові прийоми обробки даних за допомогою MapReduce;

- ознайомитися з використанням Hive для SQL-запитів до великих обсягів
даних.

Теоретичні відомості

Apache Hadoop - це платформа для зберігання та обробки великих даних на кластері комп’ютерів. Основні компоненти:

1. HDFS (Hadoop Distributed File System) - файлове сховище, яке ділить
дані на блоки та зберігає їх у розподіленому вигляді.

2. MapReduce - модель програмування для паралельної обробки даних
(Map - розбиття задачі на підзадачі, Reduce - агрегація результатів).

3. YARN - система управління ресурсами та задачами.

4. Hive - інструмент для виконання SQL-подібних запитів до даних, що
зберігаються у HDFS.

Безкоштовні інструменти для практичного заняття:

- Hadoop (Community Edition) - можна запускати в режимі standalone
або pseudo-distributed на одному комп’ютері.

- Hive - надбудова для SQL-запитів.

- Відкриті набори даних (CSV, JSON).

1. Ознайомитися з архітектурою Hadoop та принципами роботи HDFS.

2. Встановити Hadoop у pseudo-distributed mode.

3. Завантажити набір даних (наприклад, лог-файл або CSV із Kaggle/UCI)
у HDFS.

4. Виконати просту задачу MapReduce (наприклад, підрахунок кількості
входжень слів у тексті).

5. Ознайомитися з Hive та створити таблицю на основі даних у HDFS.

6. Виконати SQL-запити в Hive (вибірка, групування, агрегація).

7. Зробити висновки щодо зручності та ефективності роботи з Hadoop.
