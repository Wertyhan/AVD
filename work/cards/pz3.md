**Дисципліна:** «Аналітика великих даних»
**Тема:** «Потокова обробка великих даних засобами Apache Kafka та Spark Structured Streaming»
**Джерело:** Google Drive, файл «Практичне заняття АВД 3.pdf» (https://drive.google.com/file/d/1O1EZ_HGZgzDeDjb2FsQbDBYw6PVLopD4/view?usp=drivesdk)

## Мета роботи

Ознайомитися з принципами потокової обробки великих даних та архітектурою Apache Kafka і Spark Structured Streaming. Отримати практичні навички формування потоків даних, передавання повідомлень через Kafka та їх обробки засобами Spark у режимі, наближеному до реального часу.

## Програмне забезпечення

Для виконання роботи використовується безкоштовне програмне забезпечення:

- Apache Kafka - платформа для передавання та обробки потоків даних;
- Apache Spark - платформа розподіленої обробки;
- Spark Structured Streaming - засіб потокової обробки;
- PySpark - Python API Apache Spark;
- Python 3;
- OpenJDK;
- Docker Desktop - рекомендований засіб для спрощення розгортання Kafka;
- Jupyter Notebook або Visual Studio Code.

Усі перелічені компоненти можуть використовуватися без придбання комерційних ліцензій.

## Завдання на практичне заняття

Для роботи використовується той самий датасет Kaggle, що й у практичних роботах №1–2.

### Завдання 1. Підготовка Kafka

1. Встановити та запустити Apache Kafka.
2. Створити topic: `bigdata-topic`

### Завдання 2. Формування потоку

1. Розробити Producer, який послідовно передає записи датасету до Kafka.
2. Передбачити затримку між передаванням повідомлень для імітації потоку.

### Завдання 3. Отримання потоку

1. Створити Spark Structured Streaming-застосунок, який отримує повідомлення з Kafka.

### Завдання 4. Обробка потоку

Реалізувати:

- декодування;
- перетворення типів;
- фільтрацію;
- групування;
- статистичне агрегування.

### Завдання 5. Віконна обробка

1. Виконати аналіз даних за часовими вікнами.

### Завдання 6. Виявлення аномалій

1. Розробити правило виявлення аномальних значень у потоці.

### Завдання 7. Збереження результатів

1. Зберегти результати потокової обробки у файл або локальне сховище.

### Завдання 8. Аналіз результатів

1. Визначити закономірності, які можна виявити при потоковій обробці.

## Порядок виконання роботи

1. Підготувати Kafka та Spark.
2. Створити Kafka topic.
3. Підготувати датасет.
4. Розробити Producer.
5. Запустити передавання даних.
6. Створити Streaming-застосунок.
7. Підключити Spark до Kafka.
8. Реалізувати потокову обробку.
9. Реалізувати віконну агрегацію.
10. Реалізувати виявлення аномалій.
11. Зберегти результати.
12. Проаналізувати результати.
13. Підготувати звіт.
