## Тема

«Зберігання та аналіз великих даних у NoSQL-сховищі MongoDB»

## Мета роботи

Ознайомитися з принципами організації NoSQL-сховищ та документною моделлю MongoDB. Отримати практичні навички створення бази даних, колекцій, імпорту великих наборів даних, виконання запитів, індексації та агрегування даних. Навчитися використовувати MongoDB як сховище результатів обробки великих даних.

- MongoDB Community Edition — документно-орієнтована NoSQL СКБД;
- MongoDB Compass — графічний інтерфейс MongoDB;
- MongoDB Shell (mongosh) — командний інтерфейс;
- PyMongo — Python-драйвер MongoDB;
- Python 3;
- Jupyter Notebook або Visual Studio Code.

MongoDB може бути встановлена локально на персональному комп'ютері.
