## Теоретичні відомості (коротко, з методички)

Apache Hadoop - платформа для зберігання та обробки великих даних на кластері комп'ютерів. Основні компоненти:

1. HDFS (Hadoop Distributed File System) - файлове сховище, яке ділить дані на блоки та зберігає їх у розподіленому вигляді.
2. MapReduce - модель програмування для паралельної обробки даних (Map - розбиття задачі на підзадачі, Reduce - агрегація результатів).
3. YARN - система управління ресурсами та задачами.
4. Hive - інструмент для виконання SQL-подібних запитів до даних, що зберігаються у HDFS.

Безкоштовні інструменти: Hadoop (Community Edition) у режимі standalone або pseudo-distributed на одному комп'ютері; Hive; відкриті набори даних (CSV, JSON).
